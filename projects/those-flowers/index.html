Those Flowers are for you <3

A Computational Design Workflows final project that gathers every class exercise into one garden: flowers as digital gestures of kindness, from 2D drawing to 3D interaction, data, maps, engagement, and agents.

Aesthetic priorities

01 · Neon meadow Night black (#09010f) with bubblegum fuchsia (#ff9adf). Wireframe glow over soft depth — never purple-gradient defaults.
02 · Terminal garden Monospace voice, panel borders, and archive UI so the site feels like a living instrument, not a brochure.
03 · Daisy as thesis Bellis perennis is the recurring subject: seasonal bloom, ecology, geography, care, and collective listening.

Docs for this project live in docs/ (style system, feature plan, project ideas) and README.md. Each canvas below states intent, interaction, and sources.

Class lineage · P5.js 2D drawing

CANVAS 01 / SIGNAL BLOOM

A step-by-step construction of a daisy from an empty field — drawing as slow attention rather than instant decoration.

  • Interaction: DRAW NEXT reveals stem, leaves, petals, then center.
  • Methods: P5.js 2D primitives; no particles or wave ornaments.
  • References: Botanical line drawings; instructional flower-construction diagrams.

Class lineage · P5.js 2D atmosphere

CANVAS 02 / NIGHT GARDEN

A nocturnal bouquet study: outline and glow replace fill, so presence is suggested rather than rendered solid.

  • Interaction: Ambient animation; watch outlines and bubble contours drift.
  • Methods: P5.js stroke-led geometry, layered translucency.
  • References: Night gardens, neon signage, soft bioluminescent metaphors.

Class lineage · P5.js WEBGL / 3D form

CANVAS 03 / DATA BOUQUET

Translate the daisy into luminous 3D mass: stems, petals, cores, and perfume sparks as spatial data sculpture.

  • Interaction: Orbit / drag the camera around the bouquet.
  • Methods: P5 WEBGL cylinders, ellipsoids, spheres; soft pink materials.
  • References: Speculative botanical models; perfume as invisible spatial field.

Class lineage · 3D interaction / chance

CANVAS 04 / M'AMA NON M'AMA

The childhood petal game becomes a click ritual: each pluck toggles love / not-love, mixing folklore with computation.

  • Interaction: Click to pluck one petal; status flips M'AMA / NON M'AMA.
  • Methods: P5 WEBGL picking + state machine for remaining petals.
  • References: He loves me / he loves me not; Italian vernacular play.

Class lineage · temporal / data viz

CANVAS 05 / TEMPORAL BLOOM

Seasonality as evidence: monthly observation counts become a bloom calendar for Italy's daisy season.

  • Interaction: Read bars + bloom-index curve; peak in spring months.
  • Dataset: ~1,498 GBIF/iNaturalist-linked records of Bellis perennis (Italy), aggregated by month.
  • Methods: D3 scales, bars, and a normalized cyan index line.
1.498 RECORDS April is the dataset peak, followed by March and May. The bars are monthly observation counts; the cyan curve is normalized from 0 to 1.

Class lineage · relational / actor-network

CANVAS 06 / RELATIONAL STRUCTURES

The daisy is not alone: pollinators, nectar, meadow, and human care form a living graph of relations.

  • Interaction: Hover, drag, and click nodes to read relation stories.
  • Methods: D3 force-directed graph with typed nodes (organism, pollinator, resource, place, social).
  • References: Actor-network thinking; pollination ecology of Bellis perennis.

Class lineage · geospatial structures

CANVAS 07 / GEOSPATIAL BLOOM

Ground the metaphor in place: Italy's daisy occurrences become a seasonal map of presence.

  • Dataset: Local GeoJSON from GBIF taxon 5WH44 over a realistic OSM basemap.
  • Methods: MapLibre GL + OpenFreeMap Positron basemap; month-colored GBIF points.

Class lineage · engagement / collective poll

CANVAS 09 / SOUND GARDEN
